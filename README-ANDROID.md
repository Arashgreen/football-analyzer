# تحلیل‌گر فوتبال — نسخه اندروید

اپلیکیشن مستقل اندروید (بدون نیاز به سرور) برای تحلیل آمار فصل جاری تیم‌های فوتبال از FotMob.

## معماری
```
┌─────────────────────────────┐
│  WebView (assets/www)       │
│  index.html + app.js        │  ← همان UI نسخه وب (فارسی، RTL)
│  dataLayer.js               │  ← کلاینت FotMob (fetch مستقیم؛ CORS باز است)
└──────────────┬──────────────┘
               │ AndroidBridge (فقط برای ذخیره CSV)
┌──────────────▼──────────────┐
│  MainActivity.java          │  ← WebView + پل ذخیره فایل
└─────────────────────────────┘
```
- **بدون بک‌اند**: چون FotMob هدر `access-control-allow-origin: *` می‌فرستد، اپ مستقیم به API وصل می‌شود. اپ برای همیشه کار می‌کند حتی اگر هاست وب نسخه وب قطع شود.
- **کش در حافظه** (۱۵ دقیقه) + کش DOM WebView.

## ساخت APK — دو راه

### راه ۱: ساخت آنلاین با GitHub Actions (بدون نصب چیزی)
1. یک اکانت GitHub بسازید (اگر ندارید) و یک ریپازیتوری جدید (Public).
2. همه فایل‌های این پوشه را آپلود کنید (کشیدن و رها کردن پوشه در صفحه ریپو کافی است؛ یا با git push).
3. به تب **Actions** بروید — workflow «Build APK» خودکار اجرا می‌شود (چند دقیقه).
4. از جزئیات اجرا، artifact «football-analyzer-apk» را دانلود کنید → فایل APK داخلش است.
5. APK را به گوشی بفرستید (تلگرام/کابل) و نصب کنید. در تنظیمات گوشی، «نصب از منابع ناشناس» را برای مرورگر/تلگرام فعال کنید.

### راه ۲: ساخت روی کامپیوتر (Android Studio)
1. [Android Studio](https://developer.android.com/studio) را نصب کنید.
2. این پوشه را باز کنید (Open → پوشه پروژه).
3. منوی Build → **Build Bundle(s)/APK(s) → Build APK(s)**.
4. APK در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نصب روی گوشی
- Android 7.0 به بالا (minSdk 24).
- فایل APK را باز کنید؛ اگر پیام «منبع ناشناس» آمد، اجازه دهید و نصب کامل می‌شود.

## بهبود در آینده (نقطه‌های توسعه)
| می‌خواهید... | کجا را تغییر دهید |
|---|---|
| آمار جدید (xG، پاس، مالکیت و...) | کلید آن را در `STAT_KEYS` در `dataLayer.js` اضافه کنید + یک آیتم در `STAT_DEFS` در `app.js` |
| بازه‌بندی گل (مثلاً ۱۰ دقیقه‌ای) | تابع `goalBucketsForTeam` در `dataLayer.js` |
| منبع داده دوم | تابع `jget` را در `dataLayer.js` به یک انتخاب‌گر منبع تبدیل کنید |
| رنگ/تم | `:root` در `style.css` |
| آیکون و نام اپ | `res/` و `strings.xml` |
| نسخه جدید | `versionCode` و `versionName` در `app/build.gradle` |

## نکته‌ها
- آمار فقط برای بازی‌های تمام‌شده فصل جاری است.
- «سیو دروازه‌بان» بر اساس آمار رسمی مسابقه است و ممکن است در بعضی بازی‌ها صفر ثبت شده باشد.
- برای استفاده تجاری، شرایط FotMob را رعایت کنید.
